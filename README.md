# 여행 플래너

날짜별 경로, 구간 이동시간, 근처 맛집·카페(평점 필터), GPS 진행 확인을 한 화면에서 하는 모바일 웹 여행 플래너.
기본값은 **도식 지도 + 샘플 데이터** 프로토타입이고, `js/config.js`에서 카카오맵 모드로 바꿀 수 있다 (아래 "카카오맵 연동"). 나머지 연동은 `docs/INTEGRATION.md` 순서로 진행한다.

## 실행

```bash
npm run dev        # 정적 서버 (프로토타입, 샘플 데이터)
npm run dev:api    # api/ 서버리스까지 같이 (vercel dev, .env 필요)
```

빌드 단계는 없다. `index.html`을 열면 동작한다.

| 일정 안에서 바로 수정: 머무는 시간, 끌어서 순서 바꾸기, 이동 수단 | 완료 |
| 날짜 추가/삭제, 출발일, 일차별 시작 시각, 전체 일정 탭 | 완료 |
| 방문지별 머무는 시간 (기본 1시간, 30분 단위) | 완료 |

| 분류 자동 인식(명소·음식점·카페·숙소)과 아이콘, 직접 변경 | 완료 |
| 차선책: 근처 장소를 방문지에 연결, 지도에 점선·거리, 교체 | 완료 |
| 이 브라우저에 자동 저장 (localStorage) | 완료 |
| 카드 선택 시 지도 이동, 반경 1/3/5/10km 맛집·카페 | 완료 |
| 평점 필터, 카카오·네이버 출처 구분 | 완료 (샘플 데이터) |

| 카카오맵 (일차별 색 경로, 번호 마커, 반경 원, 이동시간 칩) | 완료 (`USE_MOCK=false`) |
| 카카오 키워드 검색으로 방문지 추가, 반경 맛집(FD6)·카페(CE7) | 완료 (평점 없음) |
| 네이버 검색 연동, 평점 매칭·캐시 | 예정 (`api/naver-local.js` 준비됨) |
| 계정 저장(로그인, 여러 여행, 공유) | 예정 |

## 구조

```
index.html          화면 골격, 스크립트 로드 순서
css/style.css       스타일 (라이트/다크 토큰)
js/config.js        공개 설정 (USE_MOCK, KAKAO_JS_KEY, API_BASE)
js/util.js          DOM 헬퍼, 아이콘
js/data.js          샘플 장소 DB, 기본 일정(trip), 화면 상태
js/core.js          시간/거리 계산, 분류, 구간(seg)·일정(sched), 근처 검색, 지도 장면(scene)
js/map.js           지도 그리기, 카메라 이동, 드래그/핀치 제스처
js/sheet.js         바텀시트 드래그
js/ui.js            날짜 탭, 일정 카드, 상세 편집, 검색 화면, 날짜 삭제
js/gps.js           내 위치, 경로 진행/이탈 계산, 시뮬레이션
js/kakao.js         카카오맵 어댑터: SDK 로드, 지도 그리기, 장소·근처 검색
js/route.js         자동차 구간 도로 경로 (api/kakao-directions 호출, 캐시)
js/main.js          시작 처리
api/naver-local.js  네이버 지역검색 프록시 (서버리스)
api/kakao-directions.js 카카오모빌리티 자동차 길찾기 프록시 (서버리스)
docs/INTEGRATION.md 실제 API 연동 계획
```

스크립트는 전역 변수를 공유하는 일반 스크립트이고, 로드 순서는 `index.html`을 따른다.
연동 단계에서 `js/map.js`를 어댑터 구조로 분리하면서 ES 모듈로 바꾸는 것을 권장한다.

## 카카오맵 연동

1. [카카오 개발자 콘솔](https://developers.kakao.com)에서 애플리케이션을 만들고 **JavaScript 키**를 복사한다.
2. 앱 설정 > 플랫폼 > **Web 사이트 도메인**에 쓸 주소를 모두 등록한다 (예: `http://localhost:3000`, 배포 도메인).
3. 제품 설정에서 **카카오맵** 사용을 켠다 (새로 만든 앱은 꺼져 있다).
4. `js/config.js`에서 `USE_MOCK: false`, `KAKAO_JS_KEY: '<JavaScript 키>'`로 바꾸고 `npm run dev`로 연다.

키가 없거나 SDK 로드에 실패하면 도식 지도로 돌아가고 안내 토스트를 띄운다.
카카오 모드에서는 위경도가 있는 장소만 쓴다. 샘플 명소에는 근사 위경도를 넣어 두었고, 샘플 맛집·카페는 도식 모드 전용이다.
일정 계산과 GPS는 위경도를 일정 중심 기준 km 평면 좌표로 바꿔(`core.js` `proj`/`unproj`) 그대로 쓴다.

### 자동차 도로 경로 (선택)

1. 카카오 개발자 콘솔 > 앱 키에서 **REST API 키**를 복사한다 (JavaScript 키와 다르다).
2. Vercel 프로젝트 > Settings > Environment Variables에 `KAKAO_REST_KEY`로 등록하고 Redeploy 한다.
3. 확인: `https://<배포 주소>/api/kakao-directions?origin=126.4929,33.507&destination=126.6697,33.5434`
   가 `{"sec":…,"m":…,"path":[…]}`를 돌려주면 된다. 오류면 카카오모빌리티 개발자센터에서 사용 신청 여부를 확인한다.

키가 없거나 호출이 실패하면 그 구간은 직선거리로 추정하고 "직선 추정"으로 표시한다.

## 환경변수

`.env.example`을 `.env`로 복사해 채운다. 네이버 키는 서버(`api/`)에서만 쓰고 클라이언트에 넣지 않는다.
카카오 JavaScript 키는 공개되므로 콘솔에서 사용 도메인을 제한한다.

## 배포

- Vercel: 저장소 연결만 하면 정적 파일과 `api/`가 같이 배포된다. 환경변수는 프로젝트 설정에 등록.
- GitHub Pages: 정적 부분만 가능하다. 네이버 프록시가 필요하면 Vercel을 쓴다.
