# 여행 플래너

날짜별 경로, 구간 이동시간, 근처 맛집·카페(평점 필터), GPS 진행 확인을 한 화면에서 하는 모바일 웹 여행 플래너.
현재는 **도식 지도 + 샘플 데이터** 프로토타입이며, 카카오·네이버 API 연동은 `docs/INTEGRATION.md` 순서로 진행한다.

## 실행

```bash
npm run dev        # 정적 서버 (프로토타입, 샘플 데이터)
npm run dev:api    # api/ 서버리스까지 같이 (vercel dev, .env 필요)
```

빌드 단계는 없다. `index.html`을 열면 동작한다.

## 기능 현황

| 항목 | 상태 |
|---|---|
| 방문지 추가, 날짜별 배치, 이동, 순서 변경, 삭제 | 완료 (샘플 DB 검색) |
| 날짜 추가/삭제, 출발일, 일차별 시작 시각 | 완료 |
| 방문지별 머무는 시간 (기본 1시간, 30분 단위) | 완료 |
| 날짜별 색 경로, 구간 이동시간, 도착·출발 시각 | 완료 (이동시간은 직선거리 추정) |
| 카드 선택 시 지도 이동, 반경 1/3/5/10km 맛집·카페 | 완료 |
| 평점 필터, 카카오·네이버 출처 구분 | 완료 (샘플 데이터) |
| GPS 진행 위치, 경로 이탈, 지연 표시 + 시뮬레이션 | 완료 (좌표 변환은 제주 도식 기준) |
| 카카오맵 / 길찾기 / 로컬 검색 연동 | 예정 |
| 네이버 검색 연동, 평점 매칭·캐시 | 예정 (`api/naver-local.js` 준비됨) |
| 저장(로그인, 여러 여행, 공유) | 예정 |

## 구조

```
index.html          화면 골격, 스크립트 로드 순서
css/style.css       스타일 (라이트/다크 토큰)
js/config.js        공개 설정 (USE_MOCK, KAKAO_JS_KEY, API_BASE)
js/util.js          DOM 헬퍼, 아이콘
js/data.js          샘플 장소 DB, 기본 일정(trip), 화면 상태
js/core.js          시간/거리 계산, 일정 계산(sched), 근처 검색(nearby)
js/map.js           지도 그리기, 카메라 이동, 드래그/핀치 제스처
js/sheet.js         바텀시트 드래그
js/ui.js            날짜 탭, 일정 카드, 상세 편집, 검색 화면, 날짜 삭제
js/gps.js           내 위치, 경로 진행/이탈 계산, 시뮬레이션
js/main.js          시작 처리
api/naver-local.js  네이버 지역검색 프록시 (서버리스)
docs/INTEGRATION.md 실제 API 연동 계획
```

스크립트는 전역 변수를 공유하는 일반 스크립트이고, 로드 순서는 `index.html`을 따른다.
연동 단계에서 `js/map.js`를 어댑터 구조로 분리하면서 ES 모듈로 바꾸는 것을 권장한다.

## 환경변수

`.env.example`을 `.env`로 복사해 채운다. 네이버 키는 서버(`api/`)에서만 쓰고 클라이언트에 넣지 않는다.
카카오 JavaScript 키는 공개되므로 콘솔에서 사용 도메인을 제한한다.

## 배포

- Vercel: 저장소 연결만 하면 정적 파일과 `api/`가 같이 배포된다. 환경변수는 프로젝트 설정에 등록.
- GitHub Pages: 정적 부분만 가능하다. 네이버 프록시가 필요하면 Vercel을 쓴다.
