# 실제 API 연동 계획

## 1. 데이터 소스

| 기능 | 소스 | 비고 |
|---|---|---|
| 지도, 경로선 | 카카오맵 JS SDK | 도메인 등록 필요 |
| 장소 검색, 반경 맛집·카페 | 카카오 로컬 API (FD6, CE7, x/y/radius) | 반경 검색 지원 |
| 구간 이동시간 | 카카오모빌리티 길찾기 | 다중 경유지 |
| 보조 검색 | 네이버 지역검색 (`api/naver-local.js`) | 반경 없음, 최대 5건, 평점 없음 |
| 평점 | 카카오 장소 상세 (비공식 호출) | 약관 위험, 아래 설계 참고 |

## 2. 코드 교체 지점

| 현재 (프로토타입) | 교체 |
|---|---|
| `js/data.js` DB, `trip` | 서버/로컬 저장소에서 로드 |
| `js/core.js` `sched()` 의 `dm`, `km` | 길찾기 API 결과로 대체 (구간 캐시) |
| `js/core.js` `nearby()` | 카카오 로컬 반경 검색 + 네이버 결과 병합 |
| `js/map.js` `pr()`, `drawMap()` | 카카오맵 오버레이(폴리라인, 마커, 원) |
| `js/gps.js` `llToXY()` | 제거. 위경도를 그대로 사용 |
| `js/ui.js` 검색 화면 | 카카오 키워드 검색 |

## 3. 병합과 평점 설계

1. 카카오 결과와 네이버 결과를 이름 정규화 + 좌표 거리(예: 50m 이내)로 같은 업체로 묶는다.
2. 평점은 카카오 장소 ID 기준으로만 붙인다. 네이버 전용 업체는 `평점 없음`.
3. 평점은 서버에 캐시(예: 24시간)해 호출 횟수를 줄인다.
4. 비공식 호출이 막히면 평점만 비워 두고 나머지 기능은 그대로 동작해야 한다 (필터는 `평점 없음` 포함 옵션 제공).
5. 장기적으로는 구글 Places 병행 또는 사용자 별점 저장으로 전환할 수 있게 평점 제공자를 한 함수로 분리한다.

## 4. 진행 순서

1. `config.USE_MOCK=false` 분기와 카카오맵 어댑터 (지도, 마커, 경로선)
2. 카카오 로컬 검색으로 방문지 추가
3. 길찾기로 이동시간 대체, 구간 캐시
4. 근처 반경 검색 + 네이버 병합 + 평점 캐시
5. GPS를 실제 위경도로 전환, 실기기 테스트
6. 저장 (여러 여행, 로그인), 공유

## 5. 주의

- 네이버 Client Secret을 클라이언트 코드나 저장소에 넣지 않는다.
- 카카오 길찾기는 호출 한도가 있으므로 같은 구간 요청은 캐시한다.
- 위치 권한은 HTTPS에서만 동작한다.
